# YSkiper — privacy policy

Публичная страница политики конфиденциальности приложения YSkiper для Android.

Адрес: https://sabadashvs.github.io/yskiper-privacy/

Репозиторий существует ради одного файла: Google Play требует, чтобы политика
открывалась по публичной ссылке, а исходный код приложения остаётся приватным.

Русская и английская версии — на одной странице, английская по якорю `#en`.
Единственный источник текста — `index.html` в этом репозитории; правки вносятся
здесь и одновременно в приватный репозиторий приложения (`privacy/index.html`).
